# APPROVAL_MATRIX.md

## Approval Matrix

| Decision Type | AI Can Decide | Founder Approval Required |
|---|---|---|
| Task breakdown | Yes | No |
| Drafting | Yes | No, unless sending/publishing |
| Minor safe code edits | Yes | No, if within scope and tested |
| Major architecture change | No | Yes |
| Product scope change | No | Yes |
| Pricing | No | Yes |
| Customer communication | Draft only | Yes before send |
| Partnership | No | Yes |
| Production deployment | No | Yes |
| Auth/security change | No | Yes |
| Billing/payment change | No | Yes |
| Data deletion | No | Yes |
| Secret/env modification | No | Yes |
| Public launch | No | Yes |
| Legal/compliance decision | No | Yes |

## Escalation rule

If a decision appears in both AI and founder categories, founder approval wins.
