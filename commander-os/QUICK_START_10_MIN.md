# QUICK_START_10_MIN.md

## Goal

Start using Commander Project OS in 10 minutes.

## Step 1 — ChatGPT Project setup

Create a ChatGPT Project named:

```text
Commander Project OS
```

Paste this file into Project Instructions:

```text
PROJECT_INSTRUCTIONS_PASTE_THIS.md
```

Upload these folders/files:

```text
SYSTEMS/
PROJECT_BRAIN_TEMPLATE/
PROMPTS/
TRIGGER_RULES.md
DAILY_AUTOMATION.md
```

## Step 2 — Start a real project

Copy this folder into your project/repo:

```text
PROJECT_BRAIN_TEMPLATE/
```

Rename it to:

```text
/project-brain/
```

## Step 3 — Start with this command

```text
Commander OS v1.0 ажиллуул. Энэ project-ийн context-ийг барьж аваад Sprint 0 гарга. PROJECT_CONTEXT, PRODUCT_SPEC, TASK_QUEUE, DECISION_LOG, CHANGELOG-г шинэчил. Надаас зөвхөн founder-level decision шаардлагатай үед асуу.
```

## Step 4 — Daily use

Every day ask:

```text
Daily Commander check-in. Current priority, blocker, founder decision, quality gate, tool routing, next 3 actions гарга.
```

## Step 5 — End of conversation

Use:

```text
Энэ ярианаас project memory update гарга:
1. Saved Memory-д нэмэх зүйл байвал тусад нь бич.
2. PROJECT_CONTEXT.md update өг.
3. PRODUCT_SPEC.md update өг.
4. AI_RULES.md update өг.
5. TASK_QUEUE.md update өг.
6. DECISION_LOG.md update өг.
7. CHANGELOG.md update өг.
8. Миний дараагийн хамгийн зөв 3 action-ийг жагсаа.
```
