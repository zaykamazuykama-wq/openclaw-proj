# INSTALLATION_GUIDE.md

## Local computer setup

Unzip this package into:

### Windows

```text
Documents\Commander_Project_OS
```

### Mac

```text
Documents/Commander_Project_OS
```

## Recommended local structure

```text
Commander_Project_OS/
├── README.md
├── PROJECT_INSTRUCTIONS_PASTE_THIS.md
├── SYSTEMS/
├── PROJECT_BRAIN_TEMPLATE/
├── PROMPTS/
├── AUDITS/
└── SMOKE_TEST/
```

## ChatGPT setup

1. Create a Project called `Commander Project OS`.
2. Paste `PROJECT_INSTRUCTIONS_PASTE_THIS.md` into Project Instructions.
3. Upload `SYSTEMS/`, `PROJECT_BRAIN_TEMPLATE/`, and `PROMPTS/`.

## Upgrade rule

Do not edit the stable package directly during a project.

Instead:
1. copy the template into the project,
2. run the project,
3. log improvements in `V1_1_BACKLOG.md`,
4. only upgrade the base OS after review.
