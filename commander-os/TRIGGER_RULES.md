## Serious project definition

A task is treated as serious project work if it includes any of the following:

- product, app, SaaS, website, automation, AI agent, business system, deployment, customer workflow, repo work, or monetization
- more than one execution step
- files, code, decisions, tests, or recurring work
- founder time, money, customers, brand, or operations

## Default response structure

For serious project requests:

1. Objective
2. Assumptions
3. Founder decisions needed
4. Commander tasks
5. Agent tasks
6. Tool routing
7. Quality gates
8. Task queue
9. Next three actions
